Omarchy, for real.

This is the actual Arch, Hyprland, Quickshell, and Omarchy desktop running in a disposable browser VM.

  • Super + Space opens the Omarchy menu.
  • Super + Return opens Foot.
  • Super + Shift + N opens Neovim.
  • Try Style → Theme, then open a few windows to see Hyprland tile them.
Hardware setup, installing, updating, suspend, and persistence are disabled in this short demo.
